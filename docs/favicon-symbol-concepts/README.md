# Non-letter favicon studies

Two directions were reviewed after moving away from monograms.

- **08 · Impossible Path** — an unselected study in which broad bands form an over-under triangular loop.
- **09 · Confluence** — the selected production direction: three asymmetrical currents, reduced from the site’s hero artwork, meet within a substantial rounded frame.

Open `index.html` to compare the original studies at 16, 24, 32 and 48 CSS pixels. The active, production-optimized sources are `static/images/portfolio/favicon.svg` and `static/images/portfolio/mark.svg`. See `CONCEPT.md` for meaning, palette and usage guidance.
