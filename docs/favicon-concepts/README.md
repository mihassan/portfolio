# M / IH favicon concepts

Archived review-only letter studies. None was selected; the live portfolio now uses the non-letter **Confluence** identity documented in `../favicon-symbol-concepts/CONCEPT.md`.

| No. | Name | Construction |
| --- | --- | --- |
| 01 | Modular Grid | Solid rounded tile with a block-built M over a compact IH grid |
| 02 | Continuous Ribbon | One open upper ribbon and soft monoline lower letters |
| 03 | Negative Hex | Letters carved from a faceted hexagonal field |
| 04 | Circular Seal | Editorial roundel with nested rings and compact letterforms |
| 05 | Diagonal Diamond | Angular letter pieces organised inside a rotated square |
| 06 | Open Monoline | Unfilled lettering held by four disconnected corner brackets |
| 07 | Asymmetric Mosaic | Three offset colour blocks, each carrying part of the monogram |
| 08 | Shared-Stem Ligature | The M’s first stem continues into I while H interlocks beside it |
| 09 | Brutalist Stencil | Heavy irregular slab, stencil cuts and a hard divider |
| 10 | Rounded Capsules | Friendly, broad strokes with soft terminals and an open silhouette |

`index.html` is the proof sheet. It deliberately shows native 16, 24, 32 and 48 CSS-pixel instances at 1×; inspect those rows rather than relying on the 128px presentation marks.

These files remain only as rejected exploration history and are not production identity sources.
