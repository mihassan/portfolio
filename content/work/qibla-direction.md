**Qibla Direction** is a focused utility I built primarily for personal use. Magnetic-compass readings can be unreliable, particularly indoors or near structures that disturb the sensor.

Instead of asking the user to trust a compass needle, the application displays the direction on a satellite map as a geodesic line.

## Landmark-based alignment

The line can be compared with a visible road, building, wall or other landmark. This turns an abstract bearing into something that can be aligned with the physical surroundings without depending on the device’s magnetic heading.

The project is complete and useful in its present form. I have considered revisiting it with newer AI-assisted development tools, but there is no scheduled redevelopment implied here.

The portfolio itself does not request location access; any permissions belong to the linked application and its current interface.
