**barebone-fsm** is a finite-state-machine gem for Ruby. Its name captures the intention: keep the useful core of the abstraction without turning it into a framework.

## States, transitions, clarity

A state machine is a straightforward way to describe what a system can do next. A small implementation should preserve the clarity of that model, rather than obscure it behind unnecessary ceremony.

The gem is an early example of my interest in focused abstractions and explicit behaviour.

## Source and releases

The RubyGems page links the release history, documentation and source. The library is published under the **MIT license**. Download totals change, so the package registry—not a permanent number on this portfolio—is the place to check them.
